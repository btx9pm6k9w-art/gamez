# Notes for AI coding sessions

- Read `HANDOFF.md` first. It has the current state, setup, code map and next steps.
- With every change, update `CHANGELOG.md` in the same commit, and update
  `HANDOFF.md` when state, setup or next steps change. Record decisions in
  `docs/DECISIONS.md`.
- `docs/DESIGN.md` is a copy of the live design doc. If the doc changes, re-export
  it here.
- Godot 4.7.2, GDScript, no binary assets in git. Log any third-party source in
  `docs/SOURCES.md` before adding it.
- Run `tools/check.sh` before pushing.
