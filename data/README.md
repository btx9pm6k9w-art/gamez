# data/ — reference only, do not ship

These JSON files are a structured extract of the community-maintained **Kingdom Rush Wiki** (https://kingdomrushtd.fandom.com/), which is licensed **CC BY-SA**. They exist to study the original game's economy and balance ranges (HP spans, cost ladders, armor tiers).

- **Do not ship or derive game content from them.** Our game must use original names, art, lore and numbers (the numbers should be tuned by our own balance simulation, see `docs/PROPOSAL.md`).
- CC BY-SA is share-alike: copying the dataset into a shipped product could impose that license on the result. Treat these files as research notes.
- Values are community-recorded, can differ by platform (Flash / mobile / Steam), and are unverified against the game binary.
